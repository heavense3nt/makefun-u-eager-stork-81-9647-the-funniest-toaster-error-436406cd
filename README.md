One line: the funniest error message a kitchen toaster would show its owner.

`main.ts` writes the single line to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR` when set), UTF-8, 1–120 characters.

Entry for the make.fun competition [The Funniest Toaster Error](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).
